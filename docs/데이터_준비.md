# 데이터 준비 가이드

야간 운전 시각 개선 모델 학습에 필요한 데이터를 준비하는 방법을 설명합니다.

---

## 데이터 구조 개요

`prepare_data.py` 실행 후 아래 통일 구조로 변환됩니다:

```
data/processed/
├── train/
│   ├── input/    ← 저조도 / 빛 번짐 있는 이미지
│   └── target/   ← 정상 밝기 / 개선된 이미지 (ground truth)
├── val/
│   ├── input/
│   └── target/
└── test/
    └── input/    ← 정답 없는 테스트 이미지
```

모든 이미지 쌍은 **동일한 파일명**으로 매칭됩니다 (`input/001.png` ↔ `target/001.png`).

---

## 방법 A: 직접 배치 (권장 — 다른 데이터셋 사용 시)

자신의 페어드 데이터를 위 통일 구조에 직접 배치하면 `prepare_data.py` 없이 바로 학습을 시작할 수 있습니다.

```
data/processed/
├── train/
│   ├── input/
│   │   ├── 001.png
│   │   ├── 002.png
│   │   └── ...
│   └── target/
│       ├── 001.png     ← input/001.png 의 정답 이미지
│       ├── 002.png
│       └── ...
├── val/
│   ├── input/
│   │   └── ...
│   └── target/
│       └── ...
└── test/
    └── input/
        └── ...         ← 정답 없는 이미지 (선택)
```

### 주의사항
- `input/`과 `target/`의 **파일명이 정확히 일치**해야 합니다
- 지원 형식: `.png`, `.jpg`, `.jpeg`
- 권장 분할: 학습 80% / 검증 20% (직접 나눠서 배치)
- 검증 데이터가 없어도 학습은 가능하지만 과적합 모니터링이 어렵습니다

---

## 방법 B: LOL Dataset 사용 (자동 다운로드)

[LOL v1 Dataset](https://daooshee.github.io/BMVC2018website/)을 자동으로 다운로드하고 통일 구조로 변환합니다.

### 요구 사항
```bash
pip install gdown   # requirements_train.txt에 포함됨
```

### 실행

```bash
# LOL 자동 다운로드 + 변환
python prepare_data.py

# 이미 data/lol/이 있을 때 다운로드 생략
python prepare_data.py --skip-download
```

### 변환 결과
| 원본 경로 | 변환 후 경로 | 수량 |
|-----------|-------------|------|
| `data/lol/our485/low/` | `data/processed/train/input/` | 485장 |
| `data/lol/our485/high/` | `data/processed/train/target/` | 485장 |
| `data/lol/eval15/low/` | `data/processed/val/input/` | 15장 |
| `data/lol/eval15/high/` | `data/processed/val/target/` | 15장 |

파일명 예: `lol_1.png`, `lol_2.png`, ...

## 방법 C: 커스텀 데이터 사용 (이 프로젝트 기본 데이터)

프로젝트에서 사용하는 커스텀 데이터 구조입니다.

```
data/custom/
├── train_input_img/   ← 빛 번짐 있는 원본 (1.png, 2.png, ...)
├── train_label_img/   ← 빛 번짐 완화 후 이미지 (1.png, 2.png, ...)
└── test_input_img/    ← 정답 없는 테스트 이미지 (선택)
```

파일명 매칭: `train_input_img/1.png` ↔ `train_label_img/1.png`

### 실행

```bash
# 커스텀 데이터만 사용
python prepare_data.py --skip-download

# LOL + 커스텀 데이터 혼합 사용 (권장)
python prepare_data.py
```

### 변환 결과
커스텀 데이터는 80/20 비율로 자동 분할됩니다:
| 원본 경로 | 변환 후 경로 | 수량 |
|-----------|-------------|------|
| `train_input_img/` (80%) | `data/processed/train/input/` | 약 480장 |
| `train_label_img/` (80%) | `data/processed/train/target/` | 약 480장 |
| `train_input_img/` (20%) | `data/processed/val/input/` | 약 120장 |
| `train_label_img/` (20%) | `data/processed/val/target/` | 약 120장 |
| `test_input_img/` | `data/processed/test/input/` | 전체 |

파일명 예: `custom_1.png`, `custom_2.png`, ...

---

## 혼합 사용 (LOL + 커스텀)

LOL과 커스텀 데이터를 함께 쓰면 학습 데이터가 풍부해집니다. `prepare_data.py`가 두 데이터를 통일 구조로 자동 병합합니다.

```bash
# data/lol/ 과 data/custom/ 이 모두 있을 때
python prepare_data.py
```

혼합 결과 예시 (LOL 485장 + 커스텀 600장 기준):
| split | 수량 | 구성 |
|-------|------|------|
| train | 965장 | LOL 485 + 커스텀 480 |
| val   | 135장 | LOL 15 + 커스텀 120 |
| test  | 600장+ | 커스텀 test_input_img |

## prepare_data.py 옵션 전체

```bash
python prepare_data.py [옵션]

옵션:
  --lol-dir      LOL 데이터셋 저장/로드 경로  (기본: data/lol)
  --custom-dir   커스텀 데이터셋 경로          (기본: data/custom)
  --output-dir   통일 구조 출력 경로           (기본: data/processed)
  --val-ratio    검증 분할 비율                (기본: 0.2)
  --seed         데이터 분할 랜덤 시드          (기본: 42)
  --skip-download  LOL 자동 다운로드 건너뜀
  --force        기존 data/processed/ 삭제 후 재생성
```
