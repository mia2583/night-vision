# 데이터 준비 가이드

학습에 사용할 데이터를 `data/processed/` 통일 구조로 만드는 방법을 설명합니다.

---

## 통일 데이터 구조

모든 학습은 아래 구조의 데이터를 사용합니다:

```
data/processed/
├── train/
│   ├── input/    ← 저조도 / 개선 전 이미지
│   └── target/   ← 정상 / 개선 후 이미지 (동일 파일명)
└── val/
    ├── input/
    └── target/
```

`input/001.png`와 `target/001.png`는 **같은 파일명**으로 쌍을 이룹니다.

---

## 방법 1: prepare_data.py 사용 (자동 변환)

`data/lol/` 또는 `data/custom/`에 데이터를 넣으면 `prepare_data.py`가 통일 구조로 변환합니다.

### LOL Dataset (자동 다운로드)

```bash
python prepare_data.py
```

LOL v1 Dataset을 자동으로 다운로드하고 통일 구조로 변환합니다.
이미 `data/lol/`이 있다면:

```bash
python prepare_data.py --skip-download
```

### 커스텀 데이터 추가

자신의 페어드 이미지를 아래 구조로 `data/custom/`에 넣으세요:

```
data/custom/
├── input/    ← 저조도 / 개선 전 이미지
└── target/   ← 정상 / 개선 후 이미지 (동일 파일명)
```

그 후 실행하면 자동으로 80/20 분할 후 `data/processed/`에 병합됩니다:

```bash
python prepare_data.py --skip-download   # LOL 없이 커스텀만
python prepare_data.py                   # LOL + 커스텀 혼합
```

---

## 방법 2: 직접 배치

변환 없이 `data/processed/`에 직접 이미지를 넣을 수도 있습니다.
분할 비율은 직접 정해서 배치하면 됩니다.

---

## prepare_data.py 옵션

```
--lol-dir      LOL 데이터셋 경로       (기본: data/lol)
--custom-dir   커스텀 데이터셋 경로    (기본: data/custom)
--output-dir   통일 출력 경로          (기본: data/processed)
--val-ratio    검증 분할 비율          (기본: 0.2)
--seed         데이터 분할 시드        (기본: 42)
--skip-download  LOL 자동 다운로드 건너뜀
--force        기존 data/processed/ 삭제 후 재생성
```
