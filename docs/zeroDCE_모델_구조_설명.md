# Zero-DCE 모델 구조 설명

**구현 파일:** `models/zerodce.py`  
**원본 논문:** Li et al., "Zero-Reference Deep Curve Estimation for Low-Light Image Enhancement", CVPR 2020

---

## 1. 전체 구조 개요

```
입력 이미지 (B, 3, H, W)
        │
        ▼
  ┌─────────────┐
  │   DCENet    │  ← 7층 CNN + 대칭 skip connection
  └─────────────┘
        │ (B, 24, H, W) 곡선 파라미터
        ▼
  ┌──────────────────┐
  │  CurveAdjustment │  ← 8회 반복 픽셀 변환
  └──────────────────┘
        │
        ▼
출력 이미지 (B, 3, H, W)
```

`ZeroDCE` 클래스가 두 모듈을 하나로 묶어 `forward(x) → (enhanced, curve_params)`를 반환합니다.  
`curve_params`는 학습 시 손실함수 계산에 사용됩니다.

---

## 2. DCENet — 백본 CNN

### 구조

```
입력 (B, 3, H, W)
  │
  ├─ Conv1: 3 → 32, 3×3, padding=1, ReLU  ──────────────────────────┐
  │                                                                    │ skip
  ├─ Conv2: 32 → 32, 3×3, padding=1, ReLU  ────────────────────┐     │
  │                                                              │     │
  ├─ Conv3: 32 → 32, 3×3, padding=1, ReLU  ──────────────┐     │     │
  │                                                        │     │     │
  └─ Conv4: 32 → 32, 3×3, padding=1, ReLU                │     │     │
              │                                            │     │     │
              └──── cat ─────────────────────────────────┘     │     │
  Conv5: 64 → 32, 3×3, padding=1, ReLU                         │     │
              │                                                  │     │
              └──── cat ──────────────────────────────────────┘     │
  Conv6: 64 → 32, 3×3, padding=1, ReLU                               │
              │                                                        │
              └──── cat ────────────────────────────────────────────┘
  Conv7: 64 → 24, 3×3, padding=1, Tanh
              │
              ▼
  곡선 파라미터 (B, 24, H, W)
```

**파라미터 수:** 79,416 개 (~79K)

### Skip Connection 방식

U-Net과 동일한 대칭 구조입니다:

| 레이어 | 입력 | 출처 |
|--------|------|------|
| Conv5 | Conv4 + Conv3 (64ch) | encoder 인접 쌍 |
| Conv6 | Conv5 + Conv2 (64ch) | encoder 인접 쌍 |
| Conv7 | Conv6 + Conv1 (64ch) | encoder 인접 쌍 |

이 구조 덕분에 **저수준 텍스처/엣지(얕은 레이어)**와 **고수준 의미 정보(깊은 레이어)**가 결합되어, 밝기를 올리면서도 세부 구조가 유지됩니다.

### Conv7 출력: 24채널의 의미

출력 24채널 = **8번 반복 × RGB 3채널**

```
채널  0~2  → 1번째 반복의 R, G, B 파라미터
채널  3~5  → 2번째 반복의 R, G, B 파라미터
...
채널 21~23 → 8번째 반복의 R, G, B 파라미터
```

Tanh 활성화로 범위는 `[-1, 1]`입니다.  
양수 A → 밝기 증가, 음수 A → 밝기 감소.

## 3. CurveAdjustment — 반복 곡선 변환

### 변환 수식

```
LE_0 = 입력 이미지 x

LE_n = LE_{n-1} + A_n * LE_{n-1} * (1 - LE_{n-1})

(n = 1, 2, ..., 8)
```

- **`A_n`**: DCENet이 예측한 n번째 반복의 R/G/B 파라미터 (픽셀별, 공간적으로 변화)
- **`LE_{n-1} * (1 - LE_{n-1})`**: 밝기가 중간(0.5)일 때 가장 민감하게 반응, 극단값(0 또는 1)에서 변화량이 0이 되는 2차 곡선
- 각 반복 후 `clamp(0, 1)`로 범위 유지

### 왜 8회 반복인가

1회만 적용하면 저조도 이미지에서 충분한 밝기 향상을 얻기 어렵습니다.  
반복할수록 곡선이 누적 적용되어 더 강한 비선형 변환이 가능합니다.  
원본 논문 실험에서 8회가 수렴 품질과 계산 비용의 균형이 가장 좋았습니다.

### 왜 픽셀별(공간 적응적) 파라미터인가

전역 단일 커브(histogram equalization 등)와 달리, DCENet이 이미지 전체를 보고 위치마다 다른 `A_n` 값을 출력합니다.  
밝은 영역(빛 번짐)은 `A_n`을 낮게, 어두운 영역은 높게 예측하여 **지역별 적응적 보정**이 가능합니다.

## 4. 원본 논문과의 차이점

### 4-1. 지도 학습 (Supervised) vs. 비지도 학습 (Unsupervised)

| 항목 | 원본 Zero-DCE | 이 프로젝트 |
|------|-------------|------------|
| 학습 방식 | 비지도 (정답 이미지 불필요) | 지도 학습 (LOL + 커스텀 페어 데이터) |
| 손실함수 근거 | Retinex 이론만으로 자체 지도 | Retinex 손실 + 페어 데이터 활용 |
| 데이터 요구 | 저조도 이미지만 있으면 됨 | 저조도/정상 쌍이 필요 |

**이유:**  
원본 Zero-DCE의 비지도 학습은 데이터 수집 부담을 낮추는 장점이 있지만, 정답 이미지가 있을 때는 지도 학습이 PSNR/SSIM 면에서 유리합니다.  
이 프로젝트는 LOL Dataset(485쌍)과 커스텀 데이터(600쌍+)의 페어드 데이터를 확보했기 때문에 지도 학습을 선택했습니다.

### 4-2. Glare Suppression Loss 추가

원본 Zero-DCE의 손실함수는 4종입니다:
- L_spa (공간 일관성)
- L_exp (노출 제어)
- L_col (색상 보존)
- L_tvA (조명 부드러움)

이 프로젝트는 **L_glare (빛 번짐 억제)** 를 추가합니다:

```
Loss = L_spa + L_exp + L_col + L_tvA + λ * L_glare
```

**이유:**  
야간 운전 영상의 핵심 문제는 전조등/가로등의 빛 번짐입니다.  
원본 Zero-DCE는 저조도 개선에 특화되어 고강도 영역 억제 기능이 없습니다.  
L_glare는 임계값(기본 0.8) 이상의 고강도 영역에 패널티를 주어 빛 번짐을 완화합니다.  
자세한 구현은 `models/losses.py` (STEP 4) 참조.

### 4-3. 모델 아키텍처는 동일

DCENet의 7층 CNN 구조, skip connection 방식, CurveAdjustment의 반복 수식은 **원본 논문과 동일**합니다.  
파라미터 수 79,416개도 원본과 일치합니다.

## 5. 클래스/함수 요약

| 이름 | 종류 | 설명 |
|------|------|------|
| `DCENet` | `nn.Module` | 7층 CNN, 24채널 곡선 파라미터 출력 |
| `CurveAdjustment` | `nn.Module` | 8회 반복 픽셀 변환, [0,1] clamp |
| `ZeroDCE` | `nn.Module` | DCENet + CurveAdjustment 통합 |
| `save_model()` | 함수 | 체크포인트 저장 (epoch, PSNR 포함) |
| `load_model()` | 함수 | 체크포인트 로드, eval 모드로 반환 |
